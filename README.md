# Mudit Todi — Robotics & Control Systems Portfolio

An interactive, 3D WebGL and control systems portfolio showcasing research and engineering projects:
- **4-DOF Robotic Manipulator with Direct MRAC** (ROS 2 Jazzy, Gazebo Harmonic, 3D Three.js Inverse Kinematics)
- **Cartpole Internal Model Control & Robust MRAC** (MuJoCo 3.x dynamics, real-time Canvas phase portraits)
- **GPS-Denied Surveillance Drone** (IMC 2025 Autonomous UAV, Pixhawk, ArduPilot, YOLOv8 edge compute)
- **Production Dual-Board PCB Architecture** (S7 Innovation Labs LLP — SEVEN Kids Companion Robot)
